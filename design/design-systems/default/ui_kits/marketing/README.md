# Pragmatic Labs — Marketing UI Kit

A pixel-leaning recreation of the marketing surface. All components live in `MarketingComponents.jsx`; `index.html` wires them into a representative homepage.

## Components (all in `MarketingComponents.jsx`)

- `Nav` — fixed top nav with logo, primary links, sign-in CTA
- `Hero` — display headline, subhead, CTA pair, supporting visual
- `LogoStrip` — "trusted by" customer logo row
- `FeatureGrid` — three-column feature cards
- `Testimonial` — single quote, author, role
- `Pricing` — three-plan tier comparison
- `Footer` — multi-column footer with wordmark

Run `index.html` for a live demo of how these compose into a homepage.
